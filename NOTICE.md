Cave Pony combines ideas from two projects. It is independently written, not a fork, and not endorsed by either.

- **[Caveman](https://github.com/JuliusBrussee/caveman)** by Julius Brussee: answer first, cut filler, keep code exact, switch to plain prose when it matters. Cave Pony 0.1 drew on the MIT-licensed snapshot [`0d95a81`](https://github.com/JuliusBrussee/caveman/tree/0d95a81d35a9f2d123a5e9430d1cfc43d55f1bb0); Caveman 3.0+ is Apache-2.0.
- **[Ponytail](https://github.com/DietrichGebert/ponytail)** by DietrichGebert (MIT): read first, take the first rung of a no-change → reuse → stdlib → dependency → new-code ladder, fix the root cause once, never cut safety. Some phrasing in `SKILL.md`, such as "take the first option that fully works" and the `shortcut:` comment form, follows Ponytail.

The eval downloads both skills at pinned commits at run time (`eval/fetch-arms.sh`). Neither is redistributed here.
